# Premium Pricing Showcase

Crie uma landing page premium em React + Tailwind CSS + Framer Motion que funcione como uma TABELA DE PREÇOS DIGITAL moderna, responsiva e extremamente atrativa.

A identidade visual deve seguir exatamente as cores da logomarca abaixo.

LOGO OFICIAL

https://i.postimg.cc/rmsQpCDY/38CDFDA1-A585-49A8-8607-152480EA799A.png

Utilize somente esta logomarca.

Ela deve ficar grande no topo.

Não alterar a logo.

==================================================

IDENTIDADE VISUAL

Criar um visual premium.

Paleta de cores:

• Preto fosco

• Azul royal

• Azul neon

• Branco

Utilizar:

✔ Fundo preto com textura em fibra de carbono

✔ Detalhes metálicos

✔ Faixas em azul neon

✔ Reflexos brilhantes

✔ Cards em vidro (Glassmorphism)

✔ Sombras modernas

✔ Efeito 3D

✔ Bordas iluminadas

✔ Ícones premium

✔ Layout extremamente elegante

Tudo deve parecer um aplicativo premium.

==================================================

TOPO

Logo centralizada.

Título:

TABELA DE PREÇOS

Subtítulo:

Confira todos os nossos serviços e escolha a melhor opção para o seu veículo.

==================================================

CRIAR CARDS PARA AS CATEGORIAS

Cada categoria deve possuir:

• Ícone grande

• Nome da categoria

• Serviços

• Preços destacados

Cada preço deve aparecer em um selo azul brilhante.

==================================================

ESTILO DOS PREÇOS

Preço dentro de uma cápsula azul metálica.

Texto branco.

Brilho 3D.

Leve animação ao passar o mouse.

==================================================

SEÇÃO SERVIÇOS

Criar todos os serviços utilizando cards modernos.

Cada card deve conter:

✔ Ícone

✔ Nome

✔ Descrição

✔ Valor

==================================================

CRIAR UMA SEÇÃO DE DESTAQUE

Título:

• Atendimento profissional

• Produtos de alta qualidade

• Equipamentos modernos

• Atendimento rápido

• Excelente acabamento

EFEITOS

Usar Framer Motion.

Fade In.

Cards subindo.

Glow azul.

Brilho metálico.

Hover moderno.

Transições suaves.

==================================================

RESPONSIVIDADE

O site deve parecer um aplicativo.

Layout perfeito para celular.

Cards grandes.

Textos bem legíveis.

Nenhuma rolagem horizontal.

==================================================

IMPORTANTE

Gerar o projeto completo.

React.

Tailwind CSS.

Framer Motion.

Código organizado em componentes.

SEO básico.

Pronto para publicação.

Não utilizar banco de dados.

Não utilizar login.

Não criar formulários obrigatórios.

Deixar todos os textos e preços facilmente editáveis para futuras alterações.
